# 🧠 Partition Equal Subset Sum (DP on Subsequences)

## 📌 Problem Statement

Given an integer array `arr[]`, determine whether it can be partitioned into **two subsets such that the sum of elements in both subsets is equal**.

---

## 💡 Key Insight (Problem Reduction)

Let total sum of array = `S`

To split into two equal subsets:

```
subset1 sum = subset2 sum = S / 2
```

👉 This reduces the problem to:

> **Find if there exists a subset with sum = S / 2**

### ⚠️ Important Condition

* If `S` is **odd**, return `false` (cannot divide equally)

---

## 🧮 Approach

This is a **Dynamic Programming (DP on Subsequences)** problem, similar to **Subset Sum**.

---

## 🚀 Solution Approaches

---

### 🔁 1. Recursive (Brute Force)

#### Idea:

At each index, choose:

* Take the element
* Skip the element

#### Code:

```java
boolean f(int index, int target, int[] arr) {
    if (target == 0) return true;
    if (index == 0) return arr[0] == target;

    boolean notTake = f(index - 1, target, arr);

    boolean take = false;
    if (arr[index] <= target) {
        take = f(index - 1, target - arr[index], arr);
    }

    return take || notTake;
}
```

#### Time Complexity:

```
O(2^n)
```

---

### 🧠 2. Memoization (Top-Down DP)

#### Idea:

Store results of `(index, target)` to avoid recomputation.

#### Code:

```java
Boolean[][] dp;

boolean f(int index, int target, int[] arr) {
    if (target == 0) return true;
    if (index == 0) return arr[0] == target;

    if (dp[index][target] != null) return dp[index][target];

    boolean notTake = f(index - 1, target, arr);

    boolean take = false;
    if (arr[index] <= target) {
        take = f(index - 1, target - arr[index], arr);
    }

    return dp[index][target] = take || notTake;
}
```

#### Time Complexity:

```
O(n * target)
```

---

### 📊 3. Tabulation (Bottom-Up DP)

#### Idea:

Build a DP table where:

```
dp[i][t] = true → subset exists using first i elements to make sum t
```

#### Code:

```java
boolean canPartition(int[] arr) {
    int n = arr.length;

    int total = 0;
    for (int num : arr) total += num;

    if (total % 2 != 0) return false;

    int k = total / 2;

    boolean[][] dp = new boolean[n][k + 1];

    for (int i = 0; i < n; i++) dp[i][0] = true;

    if (arr[0] <= k) dp[0][arr[0]] = true;

    for (int i = 1; i < n; i++) {
        for (int target = 1; target <= k; target++) {

            boolean notTake = dp[i - 1][target];

            boolean take = false;
            if (arr[i] <= target) {
                take = dp[i - 1][target - arr[i]];
            }

            dp[i][target] = take || notTake;
        }
    }

    return dp[n - 1][k];
}
```

---

### ⚡ 4. Space Optimization (1D DP)

#### Idea:

Use a single array and iterate **backwards** to avoid overwriting values.

#### Code:

```java
boolean canPartition(int[] arr) {
    int total = 0;
    for (int num : arr) total += num;

    if (total % 2 != 0) return false;

    int k = total / 2;

    boolean[] dp = new boolean[k + 1];
    dp[0] = true;

    for (int num : arr) {
        for (int target = k; target >= num; target--) {
            dp[target] = dp[target] || dp[target - num];
        }
    }

    return dp[k];
}
```

---

## 📊 Example

### Input:

```
arr = [1, 5, 11, 5]
```

### Total Sum:

```
22 → target = 11
```

### Output:

```
true
```

### Explanation:

Possible subsets:

```
[11]
[5, 5, 1]
```

---

## 🎯 Key Concepts

* DP on Subsequences
* 0/1 Knapsack Pattern
* State Transition:

```
dp[i][t] = dp[i-1][t] OR dp[i-1][t - arr[i]]
```

---

## ⚠️ Common Mistakes

* Forgetting to check if total sum is odd
* Using forward iteration in 1D DP (leads to incorrect results)
* Incorrect base case handling
